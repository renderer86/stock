# 버핏 관심종목 계산 기준 (2026-10-25)

## 가치평가 탭의 최신 실적 지표 (2026-11-28)

가치평가 순위는 `data/valuation_metrics.json`의 검증된 실적 ROE·ROA를 사용한다.
수집 대상은 네이버 ROE와 관계없는 코스피·코스닥 전 종목이다. 화면은
`data/market_sum.json`의 최신 시세와 DART 지표를 종목코드로 연결한다.
현재가·시가총액·상장주식수는 네이버에서 매일 갱신하고, ROE·ROA·EPS·BPS와
보조 자산·부채·매출/영업이익 증가율은 같은 연결/별도 기준의 DART 공시에서 가져온다.
주가가 바뀔 때 PER·PBR·괴리율을 다시 계산한다. ROE·ROA 표시 기준은 수집 범위를 제한하지 않는다.
FnGuide 과거 ROE는 가치평가에 사용하지 않으며 보조 수집은 `--include-fnguide-history`로만 실행한다.
연간 전망치(F)와 향후 12개월 전망치(12MF)는 사용하지 않는다. 분기 실적 발표 후
TTM 순이익을 `전년도 연간 + 당해 누적 − 전년 동기 누적`으로 갱신한다. ROE 분자는
지배주주 순이익, 분모는 정확히 1년 간격인 전년 동기 말·당기 말 지배주주 자본의
평균이다. ROA는 같은 기간 전체 순이익과 평균 총자산을 쓴다. 연결·별도, 법인,
통화, 회계연도와 누적·단일분기 금액을 섞지 않는다.

예: 2026년 3분기 기준 손익은 2025-10-01~2026-09-30, 평균 자본은
2025-09-30과 2026-09-30 잔액이다. 전년 동기 자본은 전년도 분기 ZIP에서 확보한다.
분기 실적의 전년 동기 누적 비교값을 우선하고 없으면 전년도 같은 분기 원본을 쓴다.
12월 결산사의 연간 실적은 3월 말, 분기는 종료 후 45일부터 필수 기준기간으로 삼으며,
더 최신의 확보된 보고서는 바로 반영한다. 최신 필수기간이나 계산 항목이 없으면
과거 네이버 ROE로 대체하지 않고 순위에서 제외한다.

다음은 적정가·수익률 산출과 순위에서 제외하며 개별 종목 상세에 사유를 표시한다.

- 기초·기말 지배주주/전체 자본이 0 이하이거나 자본금보다 작은 경우.
- 기초·기말 지배주주 자본/자산이 5% 미만인 경우.
- 최근 두 결산일에 위 자본잠식·과소자본 이력이 있는 경우.
- 중단영업이익이 양수이고 전체 순이익의 10% 이상이거나 계속영업 적자를
  전체 흑자로 바꾸는 경우. TTM 구성항목에서 중단영업 손익을 확인할 수 없는 경우도 제외한다.
- 계속영업 순손실, 지배주주 순손실, 필수 원자료 결측 또는 중대한 원본 불일치.

연결 손익에 합계나 지배주주 순이익이 생략된 경우, 같은 보고서·같은 누적기간에
명시된 `전체 순이익 = 지배주주 순이익 + 비지배주주 순이익`으로만 복원한다.
비지배주주 금액이 없거나 공란이면 0으로 추정하지 않는다. 지배주주 계속영업·중단영업
손익이 모두 명시되면 합산할 수 있으며, 중단영업이 0으로 확인된 경우에만 지배주주
계속영업 손익을 전체 지배주주 손익으로 사용한다. 명시적 기업 확장 계정코드를
인식하되 포괄손익 계정을 순이익으로 사용하지 않는다.

순위 ROE 숫자는 공시 전체 지배주주 순이익 기준을 유지하고 중단영업 왜곡은 별도로
판정한다. 전체 중단영업 손익을 지배주주 순이익에서 임의로 차감하지 않는다.
적정가의 기준 ROE는 최신 실적 ROE이며, 시나리오 범위에는 왜곡 검증을 통과한
최근 연간 ROE만 사용한다. 제외 종목을 검색해도 적정가를 산출하지 않는다.

PBR·적정가의 BPS는 최신 지배주주 자본을 우선주 포함 총 상장주식수로 나눈 근사치다.
회사명과 우선주 이름이 일치하는 우선주는 동일 발행회사의 DART 공시를 연결하고,
각 종목의 현재가로 PER·PBR을 계산한다. 단순한 종목코드 앞자리 일치로 다른 회사를 연결하지 않는다.
PER는 같은 주식수와 최근 12개월 지배주주 순이익을 사용하므로 공시 가중평균 EPS
기준과 다를 수 있다. 새 시세 수집부터 정확한 주식수를 보존하고, 기존 시세의 천 주
단위 주식수 사용 여부를 데이터에 기록한다. 손익 기간·연결/별도·자본 기준일과
시세 기준일은 표 각 지표 아래에 표시한다. 장기 재무표는 기존 연간 이력으로 구분한다.

### 공시 항목 인식 및 비교기간 보완 (2026-11-29)

손익계산서에 지배주주 순이익이 없으면 전체 재무제표 API의 자본변동표(SCE)를 확인한다.
`ProfitLoss`의 지배기업 소유주 합계 구성요소를 읽고, 자본금·이익잉여금 등 하위 항목과
합계를 중복 합산하지 않는다. 합계 행이 없으면 명시된 소유주 자본 구성요소의 순이익
배분액을 합산하되, 미확인 구성요소가 없고 전체 순이익·비지배주주 배분과 정확히
대사되는 경우만 사용한다. 분기의 연결재무제표 루트 행에는 단일 분기액이 들어갈 수
있으므로 이를 누적 손익으로 사용하지 않는다.

현금흐름표의 표준 `ProfitLoss`는 영업현금흐름과 구분하여 같은 기간 전체 순이익의
보완 근거로 사용할 수 있다. 계속영업·중단영업·전체 순이익 중 두 금액이 명시되면
나머지는 합계식으로 계산한다. 중단영업 표시가 없는 완전한 손익계산서는 세전손익과
법인세비용으로 계속영업 순이익을 복원할 수 있다. 공란 자체를 0으로 바꾸지 않는다.

로마숫자 순번, 전각 괄호, 분기·반기 순손실 등 명칭을 정규화한다. 12월 이외 결산사도
공시의 실제 기준일·보고서 코드를 사용하며, 결산월별 연간 90일·분기 45일 제출기한을
적용한다. TTM은 선택한 누적 실적 직전 연간 실적과 정확히 전년 동기 누적액을 연결한다.

`crawler_valuation_gaps.py`는 위 계산에 필요한 자료가 부족한 기업만 전체 재무제표 API로
보완한다. 상장 전 분기라 ZIP에 없는 비교기간도 포함하며, 재무상태표의 전기말 금액을
전년 동기말 자본으로 대체하지 않는다. 성공 원문은 7일, 자료 없음은 1일 후 재확인하고
호출 예산과 진행 파일을 보존한다. `income_inputs`에 종목별 기간·미확인 항목을 기록하고
화면의 제외 사유에도 실제 부족 항목을 표시한다.

시장 내재 N은 `ln(PBR) / ln((1 + ROE) / (1 + r))`로 역산하며 `r`은 10% 고정이다.
화면의 할인율·ROE 보정은 적정가 시나리오에 적용하며 시장 내재 N 입력에는 적용하지 않는다.
평가 가능한 종목에서 `0 < PBR < 1`이면 시장 N을 비교용 기준인 1년으로 고정하고
표·지속기간 상세·적정가 상세에 `1년 고정` 배지와 `PBR 1배 미만 · 비교용 가정`을 표시한다.
이는 실제 ROE가 앞으로 1년만 유지된다는 예측이나 수학적으로 역산한 기간이 아니다.
PBR이 1배 이상이면 기존 로그 역산을 적용하며, `|ROE − r| < 2%p`는 N/A다.
양의 기간으로 설명되지 않는 ROE·PBR 조합은 음수 N 대신 `역산 불가`와 사유를 표시한다.
PBR이 정확히 1배인 경우는 ROE 근접 구간을 제외하고 N=0을 유지한다.
시장 N은 표·상세의 비교용 값이며 적정가·장기 추정 수익률 계산에는 별도의 자체 추정 N을 사용한다.

```powershell
python build_valuation_metrics.py --fetch-prior-balances
python build_data_manifest.py
```

`--fetch-prior-balances`는 전년 동기 재무상태표·손익계산서 공개 ZIP만 받아 캐시한다.
생략하면 저장 원본만으로 재생성한다. 분기 갱신 워크플로에서 자동 실행하고,
국내 시세 갱신 때도 최신 주식수·시세 기준으로 계산 입력을 재생성한다.

분기 갱신 워크플로는 N·스크리닝 계산 전에 `crawler_dart_financial_bulk.py --years 1`로
최근 연간 ZIP 4종의 생성 파일명을 확인한다. 파일명이 바뀌면 전 종목 원본과 연간 패널을
갱신하고, 같으면 캐시를 사용한다. API의 과거 `013`(자료 없음) 결과가 있어도 새 ZIP에
자료가 있으면 반영한다. 2026-11-29에는 2025년 연간 8월 생성본을 11월 28일 생성본으로
교체하여 파마리서치 등의 TTM 누락을 복구했다.

첫 화면은 관심종목 목록이며 최종 매수 판정이 아니다. 현재 방법론은
`n-persistence-screens-2026-10-v2`, 스크리닝 JSON 스키마는 2다.

## 종목 식별과 원자료 검증

종목코드는 숫자·영문 6자리 식별자로 보존한다. `[0054V0]`를 `000540`으로 바꾸면
엔에이치스팩32호와 흥국화재가 합쳐지므로 문자 제거·끝 6자리 절단을 허용하지 않는다.
원본 gzip은 변경하지 않고 새 파서로 계산층을 재생성한다. 같은 연결/별도 기준의
저장 API와 대조하며, 핵심 금액의 차이가 `max(100만원, API 금액 절대값의 1%)`보다
크면 양쪽 값을 보존하고 관심종목·엄격 후보·퀄리티 바스켓 판정을 보류한다.
이는 정정공시 차이일 수도 있으므로 어느 한쪽이 무조건 정답이라고 덮어쓰지 않는다.

## 보수 ROIC

```
NOPAT = 영업이익 × (1 − 유효세율)
기말 보수 투하자본 = 자본총계 + 이자부채(리스 포함)
보수 ROIC = NOPAT ÷ 연속 두 사업연도의 보수 투하자본 평균
```

현금의 사용제한·고객자금·영업필수 여부를 일괄 검증할 수 없어 현금을 차감하지 않는다.
이는 전통적인 현금 차감 ROIC와 구분되는 보수적 비교지표이며 화면에 이름과 산식을
표시한다. 기초·기말 중 하나가 누락·비양수이면 판정하지 않는다. 금융업은 ROE를 쓴다.
예전 현금 차감 수치와 투하자본은 `detail_metrics.roic_pct`, `invested_capital`에 진단용으로
남아 있고, 선별에는 `screening_roic_pct`를 사용한다. 누락된 부채를 임의로 0으로
채우지 않는다. 유효세율은 세전이익이 양수이고 0~100%인 경우 공시값을 사용하며,
그 밖의 경우 24% 대체 여부를 기록한다.

## 리스 차감 FCF

```
기존 FCF = 영업현금흐름 − 유형자산 취득 − 무형자산 취득
리스 차감 FCF = 기존 FCF − 공시된 리스 상환액
TTM = 전년도 연간 + 당해 누계 − 전년 동기 누계
수익률 = TTM 리스 차감 FCF ÷ 저장된 시가총액
```

비교 공시의 법인·연도·통화와 연결/별도 기준이 맞고 각 구성항목이 있어야 TTM을
사용한다. 없으면 최근 연속 3년 평균을 쓰고, 이마저 부족하면 N/A로 둔다. 분기 손익의
단일분기 금액과 누계를 구분하며 상반기 현금흐름을 단순히 2배 하지 않는다.
10년 평균은 참고용으로 보존한다. 금융업은 일반기업 FCF 수익률과 전환율, 순부채
태그가 N/A다. 보험부채 총액을 현금흐름에서 빼는 방식으로 대체하지 않는다.

최신 반기/분기 자료는 `data/dart_financial_interim.json`에 API 응답 원본과 함께 저장한다.
갱신 대상은 비금융 관심종목과 기존 수집 대상이며, 같은 보고기간은 7일 캐시를 쓴다.
표시된 계산 종료일로 최신성을 확인할 수 있다. 최신 보고서의 전년 대비 영업이익
증감은 수익률과 별도로 표시한다. 원자료 수집 실패 시 연간 계산으로 대체하며
최신 자료가 있다고 표시하지 않는다.

`rebuild_financial_metrics.py`는 외부 API를 호출하지 않는다. 파서나 계산 정책이 바뀌면

최신 공시 수집은 DART 키가 있을 때만 실행한다. 금액과 비율의 결측은 통과로 세지 않는다.

## 기대수익률과 투자 비중 (2026-11-28)

괴리율과 승률 50%만으로 자동 산출하던 켈리 범위는 제거한다. 가치평가 표의 해당 열은
`장기 추정 수익률`이며, 각 시나리오에서 `r = (1 + ROE) / PBR^(1/N) − 1`을 연환산 %로
표시한다. N은 사용자 보정 후 자체 추정 N이다. 시장 N의 PBR 1배 미만 1년 고정값은
사용하지 않는다. 이익 전액 유보·일정 ROE·N년 뒤 PBR 1배 가정을 명시한다.
범위는 세 시나리오 수익률의 실제 최솟값~최댓값으로 표시하고 기준 수익률로 정렬한다.

비중 입력은 기본값을 비워 두고 브라우저 localStorage에 종목코드별로 저장한다.
실패손실률 L과 계좌 손실예산 B를 입력하면 `비중 상한 = B / L`을 계산한다.
검토 비중 w에 따른 계좌 손실은 `w × L`이며, 비중 상한은 100%로 제한한다.
0 손실예산·0 비중은 유효하지만 0 실패손실률은 나눗셈에 사용하지 않는다.
이 상한은 입력한 실패 시나리오의 손실예산 기준이며 권장 비중이나 최대손실 보장이 아니다.

선택적인 이항 켈리는 동일 평가기간 T, 상승 시 누적수익률 U, 실패손실률 L,
상승 확률 p가 모두 입력된 경우에만 `f = p/L − (1−p)/U`로 계산한다.
손익률과 확률은 소수로 변환한다. T는 N과 구분하며 상·하방 모두 같은 기간의
배당 포함 총수익률로 입력한다. 오늘의 적정가 괴리율과 N 신뢰도는 자동 대입하지 않는다.
현금 수익률 0%와 두 결과의 반복을 가정한다. 음수 켈리는 0%, 차입 없는 비중은
최대 100%로 제한하고, 1/2·1/4 켈리는 제한 전 이론값을 먼저 축소한 후 제한한다.
확률은 0% 초과 100% 미만이고 실패손실률은 0% 초과 100% 이하다.

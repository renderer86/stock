# 버핏 관심종목 계산 기준 (2026-10-25)

첫 화면은 관심종목 목록이며 최종 매수 판정이 아니다. 현재 방법론은
`n-persistence-screens-2026-10-v2`, 스크리닝 JSON 스키마는 2다.

## 종목 식별과 원자료 검증

종목코드는 숫자·영문 6자리 식별자로 보존한다. `[0054V0]`를 `000540`으로 바꾸면
엔에이치스팩32호와 흥국화재가 합쳐지므로 문자 제거·끝 6자리 절단을 허용하지 않는다.
원본 gzip은 변경하지 않고 새 파서로 계산층을 재생성한다. 같은 연결/별도 기준의
저장 API와 대조하며, 핵심 금액의 차이가 `max(100만원, API 금액 절대값의 1%)`보다
크면 양쪽 값을 보존하고 관심종목·엄격 후보·퀄리티 바스켓 판정을 보류한다.
이는 정정공시 차이일 수도 있으므로 어느 한쪽이 무조건 정답이라고 덮어쓰지 않는다.

## 보수 ROIC

```
NOPAT = 영업이익 × (1 − 유효세율)
기말 보수 투하자본 = 자본총계 + 이자부채(리스 포함)
보수 ROIC = NOPAT ÷ 연속 두 사업연도의 보수 투하자본 평균
```

현금의 사용제한·고객자금·영업필수 여부를 일괄 검증할 수 없어 현금을 차감하지 않는다.
이는 전통적인 현금 차감 ROIC와 구분되는 보수적 비교지표이며 화면에 이름과 산식을
표시한다. 기초·기말 중 하나가 누락·비양수이면 판정하지 않는다. 금융업은 ROE를 쓴다.
예전 현금 차감 수치와 투하자본은 `detail_metrics.roic_pct`, `invested_capital`에 진단용으로
남아 있고, 선별에는 `screening_roic_pct`를 사용한다. 누락된 부채를 임의로 0으로
채우지 않는다. 유효세율은 세전이익이 양수이고 0~100%인 경우 공시값을 사용하며,
그 밖의 경우 24% 대체 여부를 기록한다.

## 리스 차감 FCF

```
기존 FCF = 영업현금흐름 − 유형자산 취득 − 무형자산 취득
리스 차감 FCF = 기존 FCF − 공시된 리스 상환액
TTM = 전년도 연간 + 당해 누계 − 전년 동기 누계
수익률 = TTM 리스 차감 FCF ÷ 저장된 시가총액
```

비교 공시의 법인·연도·통화와 연결/별도 기준이 맞고 각 구성항목이 있어야 TTM을
사용한다. 없으면 최근 연속 3년 평균을 쓰고, 이마저 부족하면 N/A로 둔다. 분기 손익의
단일분기 금액과 누계를 구분하며 상반기 현금흐름을 단순히 2배 하지 않는다.
10년 평균은 참고용으로 보존한다. 금융업은 일반기업 FCF 수익률과 전환율, 순부채
태그가 N/A다. 보험부채 총액을 현금흐름에서 빼는 방식으로 대체하지 않는다.

최신 반기/분기 자료는 `data/dart_financial_interim.json`에 API 응답 원본과 함께 저장한다.
갱신 대상은 비금융 관심종목과 기존 수집 대상이며, 같은 보고기간은 7일 캐시를 쓴다.
표시된 계산 종료일로 최신성을 확인할 수 있다. 최신 보고서의 전년 대비 영업이익
증감은 수익률과 별도로 표시한다. 원자료 수집 실패 시 연간 계산으로 대체하며
최신 자료가 있다고 표시하지 않는다.

## 재생성

```powershell
python rebuild_financial_metrics.py --force
python estimate_financial_n.py --config config/financial_n_engine.json
python build_investment_screens.py
python crawler_dart_financial_interim.py --include-codes 092130,052400,215000
python build_investment_screens.py
python build_data_manifest.py
```

`rebuild_financial_metrics.py`는 외부 API를 호출하지 않는다. 파서나 계산 정책이 바뀌면
`SCREEN_METRICS_VERSION`을 올려 자동 갱신에서도 재생성이 실행되도록 한다.
최신 공시 수집은 DART 키가 있을 때만 실행한다. 금액과 비율의 결측은 통과로 세지 않는다.
